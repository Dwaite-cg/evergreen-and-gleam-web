# Individual Website Design and Development — Evergreen & Gleam

Developed by **Dontae Waite**. This project adapts the housekeeping and landscaping design concept into an original static HTML/CSS/JS student website.

## Pages and files
- `index.html` — home (root entry point)
- `pages/about.html`, `pages/services.html`, `pages/faq.html`, `pages/gallery.html`, `pages/contact.html` — five content pages
- `404.html` — Netlify-compatible 404 error page (also `pages/404.html`)
- `pages/privacy.html`, `pages/thank-you.html` — supporting pages
- `css/styles.css` — one external stylesheet; **no CSS framework or library**
- `img/` — original SVG logo, favicon and illustrations
- `vid/` — local demonstration media
- `scripts/main.js` — responsive navigation and illustrative pricing calculator
- `mockups/` — **two** original design mockups and web gallery (`mockups/index.html`)

## Color scheme and typography
The final website uses a **nature-inspired analogous green palette with warm neutral accents**, chosen to suggest calm, cleanliness, freshness and reliability. Forest `#1f493c` and deep forest `#14362d` establish credibility. Sage `#dce8d2` and leaf `#648866` suggest gardens and renewal. Cream `#f8f5ed` and paper `#fffdf8` make the layout welcoming; muted gold `#e8bd71` adds restrained warmth. Palette selected intentionally, **not generated by a palette website**.

Georgia is used for prominent headings to create a welcoming editorial feel. A sans-serif stack (Inter when available; system UI fallback) keeps body text readable. There are no external font dependencies.

## Publish on Netlify / GitHub
1. Create a GitHub repository and upload the **contents** of the `website` folder at the root. Ensure `index.html` is at repository root.
2. Visit https://app.netlify.com/ and import the GitHub repository as a new project.
3. For a plain HTML site, leave **build command empty** and choose the **publish directory** as `.`.
4. Verify Home, Contact, Gallery, FAQ, `/404.html`, and `/mockups/`. Netlify automatically serves the root `404.html` for missing URLs.
5. In Netlify, enable or verify Forms detection and form submissions. The Contact page contains a static HTML form with `data-netlify="true"`, a honeypot, and a thank-you page. You may need to redeploy after enabling form detection. Submit one test enquiry and inspect the Forms tab. The demo contact details should be replaced with genuine details before use.
6. Submit the **real** Netlify URL, GitHub repository URL, and Netlify mockup URL in your learning portal. Public URLs cannot be created without your own account authorization.
7. Open the published pages in browser DevTools, check console and Network, and test desktop/mobile views. Validator links: https://validator.w3.org/nu/ and https://jigsaw.w3.org/css-validator/.

## Privacy and authenticity
