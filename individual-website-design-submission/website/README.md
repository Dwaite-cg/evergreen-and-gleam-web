# Individual Website Design and Development — Evergreen & Gleam

Developed by **Dontae Waite**. This project adapts the housekeeping and landscaping design concept into an original static HTML/CSS/JS student website.

## Pages and files
- `index.html` — home (root entry point)
- `pages/about.html`, `pages/services.html`, `pages/faq.html`, `pages/gallery.html`, `pages/contact.html` — five content pages
- `404.html` — Netlify-compatible 404 error page (also `pages/404.html`)
- `pages/privacy.html`, `pages/thank-you.html` — supporting pages
- `css/styles.css` — one external stylesheet; 
- `img/` — original SVG logo, favicon and illustrations
- `vid/` — local demonstration media
- `scripts/main.js` — responsive navigation and illustrative pricing calculator
- `mockups/` — original design mockups 

## Color scheme and typography
The final website uses a *nature-inspired analogous green palette with neutral accents*,  to suggest calm, cleanliness, freshness and reliability. Forest `#1f493c` and deep forest `#14362d` establish credibility. Sage `#dce8d2` and leaf `#648866` suggest gardens and renewal. Cream `#f8f5ed` and paper `#fffdf8` make the layout welcoming; muted gold `#e8bd71` adds restrained warmth. Palette selected intentionally to match the evergreen name.

Georgia is used for prominent headings to create a welcoming editorial feel. A sans-serif stack keeps body text readable. There are no external font dependencies.

The following public websites were selected for design-study inspiration; they are **not sources of copied code**:

2. https://www.maidpro.com/ — clear cleaning-services presentation.
3. https://www.trugreen.com/ — garden/lawn-care organization and messaging.
4. https://www.brightview.com/ — landscaping brand and imagery direction.
5. https://www.taskrabbit.com/ — concise service discovery and calls to action.

## Privacy and authenticity
Evergreen & Gleam is a fictional company. Service prices, phone numbers, email addresses, images and media are illustrative project assets. The illustration SVGs and two mockups were created for this project. The Netlify contact form collects visitor-submitted information when deployed; see `pages/privacy.html`.
